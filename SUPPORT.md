# Getting help

- Installation or setup questions: start with [docs/installation.md](docs/installation.md), then ask in [Discussions](https://github.com/theseven1/Rayward-Vencord-User-Plugin/discussions).
- Something broken: open a [bug report](https://github.com/theseven1/Rayward-Vencord-User-Plugin/issues/new?template=bug_report.yml).
- A result that doesn't match what the source shows: use the [source result form](https://github.com/theseven1/Rayward-Vencord-User-Plugin/issues/new?template=source_result.yml).
- Disputing a flag: contact the source through the Appeal link on its card in the full report. This project can't change a source's result.
- API keys and access: apply and manage your key at [rayward.app](https://rayward.app).
- Vencord problems that happen with this plugin disabled: ask in the [Vencord support server](https://vencord.dev/discord).
