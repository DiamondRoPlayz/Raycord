# Changelog

## 1.0.0 (2026-11-24)

First public release.

### Features

- Profile section and full report with an overview, one card per source and linked Roblox accounts
- Sources come from Rayward's source list, each with its own switch in settings
- Each source is looked up, cached and retried on its own, so one failing source never hides the others
- Source cards show status, reasons, evidence, review details and the source's appeal link
- Rotector's linked Roblox accounts, possible alts, tracked Discord servers and other Discord accounts on the same Roblox account
- Optional EASI lookups for linked Roblox accounts
- Confirmation before the first message, sticker or wave to a flagged user
- Member list and chat markers, a warning under a flagged user's first message, and DM notifications
- `/rayward`, `/rayward-roblox` and `/rayward-group` commands with embed replies
- Results cached for up to seven days; failed lookups are never cached
- Settings and "don't warn me again" choices carry over from CatchThem
